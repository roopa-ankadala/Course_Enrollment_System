# Course Enrollment System (CES)

## 📌 Project Overview
The **Course Enrollment System (CES)** is a web-based application developed using Python, Streamlit, and MySQL. It simplifies the process of managing students, courses, and course enrollments through a user-friendly interface.

The system allows administrators to manage student information, add courses, enroll students, and monitor enrollment activities through reports and dashboards.

## 🚀 Features

- **Login System:** Secure login functionality for authorized access.
- **Dashboard:** Displays an overview of students, courses, and enrollments.
- **Student Management:** Add and manage student details.
- **Course Management:** Add courses with instructor names, duration, capacity, and fees.
- **Course Enrollment:** Enroll students in available courses.
- **Reports & Analytics:** View enrollment statistics and summary reports.
- **Database Integration:** Store and manage records using MySQL.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the Project Folder

```bash
cd Course-Enrollment-System
```

### 3. Install Required Dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure MySQL Database

- Create a MySQL database.
- Create the required tables.
- Update the database connection details in `db.py`.

### 5. Run the Application

```bash
streamlit run app.py
```
